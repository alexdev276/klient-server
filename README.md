# Инструкция по работе с сетевым приложением (ЛР 4 и ЛР 5)

Данное приложение реализует архитектуру "Клиент-Сервер" на базе фреймворка Qt (C++) и объединяет функционал двух лабораторных работ:
1. **Сетевой чат (ЛР 4)**: обмен текстовыми сообщениями между всеми подключенными клиентами через сервер.
2. **Распределенные вычисления (ЛР 5)**: сервер распределяет математическую задачу между клиентами, клиенты вычисляют свои части и возвращают результаты на сервер для объединения.

## 1. Сборка и запуск
1. Откройте файл `NetworkApp.pro` в Qt Creator.
2. Соберите проект (Build -> Build Project).
3. Запустите приложение. При старте появится диалоговое окно с выбором режима: **Сервер** или **Клиент**.
   * *Примечание:* Для полноценной работы необходимо запустить **один** экземпляр в режиме "Сервер" и **два или более** экземпляра в режиме "Клиент".

## 2. Архитектура и Паттерн Adapter
В проекте реализован паттерн **Adapter**, который скрывает низкоуровневую работу с `QTcpSocket` и обеспечивает надежный протокол передачи данных.
* `ISocketAdapter` — абстрактный интерфейс.
* `SocketAdapter` — базовый класс, реализующий протокол с заголовком размера (`quint16`).
* `ServerSocketAdapter` и `ClientSocketAdapter` — конкретные реализации для сервера и клиента.

## 3. Сценарий А: Сетевой чат (ЛР 4)
1. В окне клиента введите любой текст в поле ввода.
2. Нажмите **"Отправить в чат (ЛР4)"**.
3. Клиент отправляет на сервер команду `CHAT:<текст>`.
4. Сервер принимает сообщение и рассылает его всем остальным подключенным клиентам (broadcast). Сообщение появляется в их логах.

## 4. Сценарий Б: Распределенные вычисления (ЛР 5)
*В рамках приложения реализован Вариант 1 из ЛР5: Нахождение площади фигуры при Y > 0 для функции Y = sin(x).*
1. Подключите к серверу **два или более** клиентов.
2. В окне любого клиента нажмите кнопку **"Запустить вычисления sin(x) (ЛР5)"**.
3. Клиент отправит на сервер команду `CALC_START:0:12.56:400` (вычислить площадь на отрезке [0, 4π], разбив его на 400 подзадач).
4. **Сервер** автоматически разделит 400 подзадач поровну между всеми активными клиентами (по кругу) и разошлет им команды вида `TASK:id:a:b`.
5. **Каждый клиент**, получив задачу, локально вычисляет интеграл (методом прямоугольников) для своего отрезка `[a, b]`, учитывая только значения, где `sin(x) > 0`, и отправляет результат обратно на сервер (`CALC_RES:id:value`).
6. **Сервер** накапливает результаты. Когда все подзадачи будут выполнены, сервер рассылает всем клиентам итоговое сообщение: `CALC_FINAL:<значение>`.
7. Ожидаемое значение площади: **~8.000000** (так как площадь одного периода синуса выше оси X равна 2, а на отрезке 4π таких периодов ровно 4).

## 5. Протокол сообщений
* `CHAT:<text>` — сообщение для чата.
* `CALC_START:<A>:<B>:<Steps>` — команда инициации вычислений.
* `TASK:<id>:<a>:<b>` — задача от сервера к клиенту.
* `CALC_RES:<id>:<value>` — отчет о вычислении от клиента к серверу.
* `CALC_FINAL:<value>` — итоговый результат от сервера ко всем клиентам.
