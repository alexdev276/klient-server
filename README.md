# Клиент-сервер на Qt: ЛР6 и ЛР7

Консольное приложение на Qt 6 (C++17) с четырьмя режимами работы:

| Режим      | Назначение                                              | Порт по умолчанию |
|------------|---------------------------------------------------------|-------------------|
| `server6`  | UDP-сервер чата (ЛР6)                                   | 5555              |
| `client6`  | UDP-клиент чата (ЛР6)                                   | 5555              |
| `server7`  | Сервер распределённого подбора ключа Виженера (ЛР7)     | 50050             |
| `client7`  | Клиент распределённого подбора ключа Виженера (ЛР7)     | 50050             |

## Сборка

1. Откройте `CMakeLists.txt` в Qt Creator и соберите проект.
2. Или из терминала:

```bash
cmake -S . -B build
cmake --build build
```

Требуется Qt 6 с модулями `Core` и `Network`.

## Запуск

Без аргументов программа показывает меню выбора режима. Режим можно задать и аргументом:

```bash
./klient-server server6 [порт]
./klient-server client6 [адрес] [порт]
./klient-server server7 [порт]
./klient-server client7 [адрес] [порт]
```

Локально:

```bash
./klient-server server7          # терминал 1
./klient-server client7          # терминал 2
```

По сети (сервер на ноутбуке `192.168.1.45`):

```bash
./klient-server server7          # на серверном ноутбуке
./klient-server client7 192.168.1.45 50050
```

## ЛР6 — UDP-чат

Клиент отправляет введённые строки на сервер, сервер отвечает `Сервер получил: <текст>`.
Выход — команда `exit`. Пустые строки не отправляются.

## ЛР7 — распределённый поиск ключа

Сервер раздаёт клиентам диапазоны ключей по 1000 значений: 1000–1999, 2000–2999, …,
9000–9999 и отдельно 10000. Клиент перебирает ключи в полученном диапазоне, расшифровывая
шифртекст, и ищет фразу `is120`.

Протокол (UDP, текстовые датаграммы):

- `HELLO` / `NEXT` — запрос задания; ответ `шифртекст|начало|конец`;
- `RETRY` — повтор последнего выданного этому клиенту задания (защита от потери датаграмм);
- `FOUND: <ключ>` — клиент нашёл ключ;
- `NO_MORE_TASKS` — задания закончились либо поиск уже завершён.

Клиент ждёт ответ 3 секунды и делает до 5 попыток, после чего завершается с сообщением об
ошибке. Найдя ключ, клиент отправляет его серверу и выходит; сервер печатает найденный ключ
и останавливает выдачу заданий.

Шифртекст и диапазон ключей заданы в `udpserver.cpp`. Чтобы заменить демонстрационные
данные, сформируйте новый шифртекст тем же алгоритмом:

```cpp
QString cipher = Vigenere::encrypt("открытый текст с фразой is120", "7351");
```

Ключ должен попадать в диапазон 1000–10000.

## Алгоритм Виженера

`vigenere.cpp` использует алфавит из методических указаний (кириллица с `Ё`, латиница,
цифры и знаки). Дубли символов в исходной строке отбрасываются. Позиция в ключе
увеличивается только на символах, входящих в алфавит, поэтому символы вне алфавита не
сбивают расшифровку. Реализованы `encrypt()` и `decrypt()`.

Файлы старой TCP-версии (`mainwindow.*`, `server.*`, `client.*`, адаптеры,
`vigenereclient/vigenereserver/vigenereworker`) оставлены в папке, но в сборку не входят.
