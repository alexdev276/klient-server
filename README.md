# Сетевое приложение "Клиент-Сервер" (ЛР 4 и ЛР 5)

Данный проект реализует архитектуру клиент-сервер на базе фреймворка Qt (C++) с использованием паттерна проектирования **Adapter**. Приложение объединяет функционал двух лабораторных работ:
1. **ЛР 4**: Сетевой чат (обмен текстовыми сообщениями между клиентами через сервер).
2. **ЛР 5**: Распределенные вычисления (сервер разбивает математическую задачу на подзадачи, распределяет их между клиентами, собирает и суммирует результаты).

**Вариант 1 (ЛР 5):** 
* Функция: $Y = \sin(x)$
* Искомая величина: Площадь фигур при $Y > 0$
* Точность: $10^{-6}$

---

## 🛠 Сборка проекта
1. Откройте файл `CMakeLists.txt` в **Qt Creator**.
2. Убедитесь, что в `CMakeLists.txt` подключен модуль `Network` (`find_package(Qt6 REQUIRED COMPONENTS Core Gui Network Widgets)`).
3. Выполните сборку проекта: **Сборка** -> **Собрать проект "klient-server"**.

---

## 💻 Запуск на одном компьютере (Локальная сеть)

1. Нажмите кнопку **Run** (Зеленая стрелка).
2. В появившемся диалоговом окне выберите **Сервер**.
   * *Графического окна не будет.* Смотрим в нижнюю панель Qt Creator (**Application Output**). Там должно появиться: `=== СЕРВЕР ЗАПУЩЕН НА ПОРТУ 5555 ===`.
   * **Не останавливайте программу!**
3. Нажмите кнопку **Run ЕЩЕ РАЗ** (запустится вторая копия приложения).
4. В новом диалоговом окне выберите **Клиент**.
   * Откроется графическое окно клиента. В консоли сервера появится сообщение о новом подключении.

## 📶 Запуск на разных ноутбуках (По Wi-Fi)

Чтобы запустить сервер на одном ноутбуке, а клиент на другом, подключенных к одной Wi-Fi сети, выполните следующие шаги:

### Шаг 1. Узнайте IP-адрес серверного ноутбука
* **macOS**: Зажмите `Option` и кликните по значку Wi-Fi в верхней панели. Найдите строку `IP Address` (например, `192.168.1.45`).
* **Windows**: Откройте командную строку (`cmd`) и введите `ipconfig`. Ищите `IPv4-адрес`.

### Шаг 2. Измените код клиента
Откройте файл `clientsocketadapter.cpp` и замените `127.0.0.1` на **IP-адрес вашего серверного ноутбука**:
```cpp
// Было: m_ptcpSocket->connectToHost("127.0.0.1", 5555);
m_ptcpSocket->connectToHost("192.168.1.45", 5555); // Вставьте ваш IP
